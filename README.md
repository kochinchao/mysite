## 📖 關於本專案 (About This Repository)

本專案為個人形象與作品集網站的原始碼，採用現代化前端技術與簡約大器的 Pinterest 優雅大地色系風格設計。網站融合了 **SEO / GEO / AEO 結構化資料**，並完整整合了前端互動邏輯與 **Google Apps Script 後端聯絡表單**，實現零伺服器成本的表單留言自動寫入 Google Sheets 功能。

---

## 🛠️ 技術與工具堆疊 (Tech Stack)

* **前端介面**：HTML5, Tailwind CSS (CDN), JavaScript (ES6+)
* **圖示與字型**：FontAwesome, Google Fonts (Noto Sans TC)
* **搜尋引擎優化與結構化**：Open Graph Meta Tags, Schema.org JSON-LD (Person)
* **後端與自動化**：Google Apps Script (GAS), Google Sheets API
* **AI 與專案工具**：Gemini, ChatGPT, Claude, Notion, Asana
